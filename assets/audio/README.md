# FocusMate 音频素材目录

## 📁 文件命名规则

将以下 10 个音频文件放入本目录即可替换程序化生成的环境音：

| 文件名 | 描述 | 建议时长 |
|--------|------|---------|
| `rain.mp3` | 雨声（中雨/小雨） | 30-60s |
| `thunder.mp3` | 雷雨（雨声+远雷） | 60-120s |
| `forest.mp3` | 森林（鸟鸣+树叶沙沙） | 30-60s |
| `crickets.mp3` | 虫鸣（夜晚蟋蟀/蛙声） | 30-60s |
| `waves.mp3` | 海浪（潮起潮落） | 60-120s |
| `river.mp3` | 河流/溪流 | 30-60s |
| `fire.mp3` | 壁炉（柴火噼啪） | 30-60s |
| `cafe.mp3` | 咖啡厅（人声嘈杂） | 60-120s |
| `wind.mp3` | 微风（呼呼风声） | 30-60s |
| `piano.mp3` | 轻音乐（钢琴/环境音乐） | 120-300s |

## ⚙️ 技术要求

- **格式**：MP3（兼容性最好）或 OGG / WAV
- **采样率**：44100Hz
- **声道**：单声道或立体声均可
- **音质**：128kbps+ 即可
- **循环**：音频需要能无缝循环播放（首尾平滑衔接）
- **音量**：统一标准化到 -14 LUFS 左右

## 🔗 推荐免费素材来源（CC0 / 免费商用）

1. **Freesound.org** - https://freesound.org
   - 最大的免费音效库，搜索关键词如 "rain loop", "forest ambience"
   - 注意选择 CC0 或 Creative Commons 许可的素材

2. **Pixabay Music** - https://pixabay.com/music/
   - 完全免费商用，无需署名
   - 搜索 "ambient", "nature sounds"

3. **Mixkit** - https://mixkit.co/free-sound-effects/
   - 高质量免费音效，直接下载
   - 分类清晰，有专门的 Nature / Ambient 分类

4. **BBC Sound Effects** - https://sound-effects.bbcrewind.co.uk
   - BBC 开放的 16000+ 音效库
   - 注意许可证限制（个人/教育用途免费）

5. **Zapsplat** - https://www.zapsplat.com
   - 大量免费环境音，注册即可下载

## 💡 使用方法

1. 从上述网站下载对应音效
2. 使用 Audacity 等工具裁剪为合适时长
3. 确保首尾能平滑循环（Audacity: Effect → Crossfade）
4. 导出为 MP3 格式
5. 按上表命名，放入本目录
6. 刷新 FocusMate 页面，系统会自动加载真实音频替换程序化生成
